# WebTV · 免费网络电视与点播（单文件网页版）

一个纯静态单文件网页播放器（`index.html`），无需安装 App，手机 / 电脑浏览器打开即可使用。

## 功能

- 直播：内置公开免费频道、一键添加 iptv-org 公开频道表、国内直播源精选、订阅自定义 M3U / JSON / TVBox 配置。
- 点播：「我的点播库」可添加自己的 mp4/m3u8 直链或 B 站链接（只存本机）；B 站官方播放器；archive.org 公版片库「最近更新」与搜索，均可直接播放。
- 追番：Bangumi 每日更新表，B 站官方播放器看番。
- 收藏 / 历史 / 统一搜索 / 分组折叠，数据保存在浏览器本地。

## 部署（GitHub Pages，免费）

本仓库 `main` 分支即为站点源：

1. 仓库 Settings → Pages → Source 选择 `main` 分支 / root → Save
2. 等待 1–2 分钟，访问 `https://<用户名>.github.io/webtv/`

每次更新只需提交 `main` 分支，Pages 会自动重新发布。

## 本地运行

```bash
python -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123
```

## 说明

- 浏览器无法播放 udp/rtp 组播源；部分源因跨域、UA/Referer 限制或失效而无法播放，属正常现象。
- 仅播放有合法授权的来源；公版作品为版权已过期的老作品，合法免费。
- 我的点播库保存在当前浏览器本地，不跨设备同步。
